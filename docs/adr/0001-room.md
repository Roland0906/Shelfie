# 0001. Room

Accepted · 2026-10-05

Local storage uses Room with the bundled SQLite driver. It gives `Flow` queries, a generated `PagingSource` for search and transactions, and it runs on Kotlin Multiplatform, so an iOS target can reuse the same DAOs. SQLDelight was the alternative; Room needed less code for paging. The cost is KSP in the build, and every schema change needs a migration once the app is released.
